# raw/ — zdrojové materiály

Neměnná vrstva wiki. Sem patří originální podklady: poznámky z brainstormingu,
přepisy rozhovorů, reference na jiné hry, články, obrázky, moodboardy.

- LLM odsud **pouze čte**, nikdy soubory neupravuje ani nemaže.
- Pojmenování: `YYYY-MM-DD-kratky-popis.md` (např. `2026-09-22-zakladni-koncept.md`).
- Obrázky a binární přílohy do `raw/assets/`.
- Po přidání zdroje řekni Claudovi „ingest raw/<soubor>“ a on znalosti zapracuje do `wiki/`.
